# Trabalho Final Mininet - C115

Trabalho desenvolvido para a disciplina **C115 - Conceitos e Tecnologias para Dispositivos Conectados**.

O projeto utiliza o **Mininet** para simular topologias de rede com hosts, switches e testes de comunicação.

## Tecnologias

- Python
- Mininet

## Arquivos

- `custom_topo.py`: código da topologia customizada desenvolvida em Python.
- `Relatório final mininet.pdf`: relatório final do trabalho.
- `Relatório final mininet.docx`: versão editável do relatório.

## Sobre o trabalho

O trabalho aborda a criação de topologias no Mininet, análise de interfaces, endereços, portas e testes de comunicação entre os dispositivos da rede.
